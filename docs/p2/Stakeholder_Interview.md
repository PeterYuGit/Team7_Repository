
# Interview Transcript

Interviewee: Bookstore owner  
Interviewer: Peter  
Date: 11/05/2026  
Location/Method: Email  
Purpose: Directly elicitation of stakeholder needs

## Interview

Interviewer: “We're currently working on an automated system for sorting books into categories on how they'll be shipped, would this be something useful for your business?”

Interviewee: “No at the current moment, but it would be useful when we expand our operations more in the future.”

Interviewer: “Do you agree with our thresholds in Table 3.1 (attached below) on categorizing books for shipping or is there anything we should change?”

Interviewee: “This is similar to my process on deciding how to ship, however I do take extra care on books that I think have collector's value by bubble wrapping it and shipping in a reinforced box regardless of weight.”

Interviewer: “Do you have any further thoughts or concerns we should consider?”

Interviewee: “Besides adding additional shipping protection on books I deem more valuable, the rest looks good.”

## Key Finding

-   Need 1: Add additional functional requirement for books marked as "valuable" by the bookstore owner to be placed into the reinforced box category regardless of weight.
    

## Follow-Up Actions

-   Asked if there were other changes that needed to be made- received approval for the rest of Table 3 thresholds.
