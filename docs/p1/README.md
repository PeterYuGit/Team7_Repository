# BookPack — P1 documentation guide

Team 7 · CE/CS/SE 3354 Software Engineering · Fall 2026

This folder contains the individual Markdown sources and diagrams that make up **BookPack's P1 baseline**. BookPack assists packing employees with capturing book measurements, recommending packaging, flagging books that require inspection, and updating existing shipping records.

## Start here

1. [Introduction and scope](introduction-and-scope.md) — why BookPack exists and what is in and out of scope.
2. [System context](context.md) and [context diagram](context-diagram.png) — the system boundary and external interactions.
3. [Stakeholder information](StakeholderInfo.md), [user characteristics](user-characteristics.md), [feasibility](feasibility.md), and [assumptions](assumptions.md) — people, constraints, dependencies, and uncertainty.
4. [Functional requirements](function-requirements.md), [quality requirements](quality-requirements.md), and [constraint requirements](constraint-requirements.md) — what the system must do and how it will be checked.
5. [Use cases](use-cases.md) and [use-case diagram](use-case-diagram.png) — actor goals and key interaction flows.
6. [Requirements traceability matrix](requirements-traceability-matrix.md) — how functional requirements relate to use cases.
7. [Project plan](project-plan.md) and [open questions](open-questions.md) — roles, risks, milestones, and stakeholder decisions still needed.

Additional source details appear in [constraints](constraints.md), [definitions](definitions.md), and [references](References.md).

## Baseline and subsequent changes

These sources are the **P1 baseline**, not automatically the current P2 specification. P2 carries them forward but records the changed FR-08 weight-flag tolerance, FR-09 priority, and weight-plus-thickness classification rule (CH-01/02/03). P2 design artifacts are in [`../p2/`](../p2/), and scale-read evidence is under [`../../spikes/S-01-scale-read/`](../../spikes/S-01-scale-read/).

The bookstore's actual scale and agreement on Table 3.1 classification thresholds have not yet been verified. Check the current P2 open questions and change log before treating P1 assumptions as settled.

For contribution evidence, refer to the repository commit/PR history and the contribution table in the applicable milestone submission.
