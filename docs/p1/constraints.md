# P1 Section 2.4 Constraints

| # | Constraint | Type | Source |
|---|---|---|---|
| C1 | No package recorded by the system may exceed 70 lb, the USPS maximum package weight. | External | USPS link (Section 1.4) |
| C2 | The system needs to store weight in pounds and length, width, thickness in inches. | External | USPS link (Section 1.4) |
| C3 | The system needs to run on the packing station's existing computer system and scale. The bookstore will not buy new hardware. | External | Assumed. Not yet confirmed with the bookstore (Q3). |
| C4 | All project artifacts must be in a GitHub repo the instructor is able to access. | Organizational | P1 template |
| C5 | Available box sizes for packaging at the store/distributor may be limited. | External | Assumed: not all stores have all box sizes; pending bookstore confirmation. |

C1 to C3 are carried forward into Section 3.3 as CON-01 to CON-03. C4 constrains the project, not the product, so it is not carried forward.

C5 describes an assumed physical limitation on packaging availability. It does not, by itself, introduce inventory tracking or automated box-stock checks.
